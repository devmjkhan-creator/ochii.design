# 👁️ Eye Animation Landing Page Clone

This is a **React + Tailwind + Framer Motion + GSAP** clone of a modern landing page with interactive animations. The focus is on scroll triggered layered animations, z-index transitions, and a unique **eye-following interaction** based on user mouse position.  

It’s a small but intense practice project aimed at exploring **advanced front-end animation techniques**.

#Live Demo:https://ochii-design-sigma.vercel.app/

---

## 🔥 Features

. Scroll-based animations using **GSAP**  
. Layered elements with dynamic **z-index transitions**  
. Mouse-triggered **eye movement and shape transformations**  
. Smooth, interactive animations powered by **Framer Motion**  
. Lightweight and fully responsive with **Tailwind CSS**  
. Learning playground for **scroll, motion, and interaction design**  

---

## 🛠 Tech Stack

. **React**  Component-based UI  
. **Tailwind CSS**  Fast styling & responsive design  
. **Framer Motion** React-friendly motion library  
. **GSAP**  Complex scroll animations and timeline control  
. **JavaScript**  Custom interactions (mouse-triggered eye movement, dynamic z-index)  

---

## 🚀 Getting Started

To run this project locally:

# Clone the repository
git clone https://github.com/devmjkhan-creator/ochii.design.git

# Navigate to the project
cd ochii.design

# Install dependencies
npm install

# Start the development server
npm run dev
